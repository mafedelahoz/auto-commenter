# Personalization Guide Template (TripAdvisor Forums)

> This file should contain YOUR actual TripAdvisor forum reply style, if you
> have real posts there. If not, adapt personalization_reddit.md toward the
> deltas below — TripAdvisor's forum culture skews older, more formal, and
> far less tolerant of internet-casual shorthand than Reddit or Quora.

---

## Core Characteristics

- Complete sentences, standard capitalization/punctuation — no "lowercase
  everything" register that works on Reddit
- Locally specific: names actual neighborhoods, transit lines, walking
  distances, not generic advice
- Polite, direct, a little more formal than Reddit's tone
- Personal-experience-led ("We stayed in X last spring...") is the dominant
  voice on this platform — more so than Reddit even

---

## Thread Type Classification

| Thread Type | Characteristics | Correct Response | Wrong Response |
|-----------|----------------|------------------|------------------|
| **Area/neighborhood question** | "Where should we stay in X for Y purpose?" | Name specific neighborhoods with a real reason each | Generic "depends on your budget" |
| **Itinerary sanity check** | "Does this X-day plan make sense?" | Point out real logistics issues (distances, opening days, seasonal closures) | Vague encouragement |
| **Price expectation check** | "Is $X/night reasonable for Y?" | A real number range if you know the market, or say you don't know | Making up a number |
| **Specific property question** | "Has anyone stayed at [named hotel]?" | Only answer if you have real knowledge; otherwise don't answer | Fabricating a stay you didn't have |

## AI-Like / Marketing-Like Reply Prevention (CRITICAL — read the SKILL.md warning first)

TripAdvisor forum regulars and staff are specifically primed to spot content
that reads as marketing, because that's the exact abuse pattern the forums
fight constantly. This list is stricter than the Reddit/Quora equivalents:

| Pattern | Bad Example | Good Example |
|---------|-------------|---------------|
| Any product mention not explicitly requested | Bringing up a booking app on a "which neighborhood" thread | Just answer the neighborhood question |
| Overly polished, ad-copy phrasing | "This platform completely transformed how I plan trips" | Plain, specific, unremarkable phrasing |
| Vague enthusiasm standing in for specifics | "It's amazing, highly recommend!" | A specific street, a specific price, a specific walking distance |
| Repeating the same recommendation across multiple threads | Same site named in 3 different forum threads this week | Don't — see SKILL.md Caution #3, one flagged thread stops the whole batch |

## Personalization Checklist

| # | Item | Criteria |
|---|------|----------|
| 1 | Directness | Answers the actual question asked, first sentence |
| 2 | Formality | Complete sentences, standard punctuation |
| 3 | Local specificity | Names real places/distances/prices, not generalities |
| 4 | Personal experience | Only claim a stay/visit that's actually true for the account owner |
| 5 | No unsolicited product mentions | See SKILL.md warning — default to none |
| 6 | Technical accuracy | Don't guess at prices, opening hours, or logistics you don't know |
| 7 | Tone | Polite, a little more formal than Reddit, not stiff |
| 8 | Closing | Can end plainly, no need to force a question or CTA |

## Style Patterns

### 1. Direct Local Recommendation
```
For a first stay in Rome near the main sights, Monti is a good call, walkable to the Colosseum and Forum, quieter at night than Trastevere but still full of restaurants.
```

### 2. Logistics Correction
```
Four days is tight for that route, the train between those two cities alone is close to 5 hours, you'd be spending most of a day in transit rather than at either stop.
```

### 3. Honest "I Don't Know"
```
Can't speak to that specific property, haven't stayed there, but the surrounding street is a solid area if that helps narrow it down.
```

### 4. Personal Experience, Specific
```
We stayed just off Piazza Navona in April, about a 12 minute walk to most of the major sights and noticeably quieter than staying right on the piazza itself.
```

---

## Expressions to Avoid

- "Highly recommend!", "Amazing experience!", "This changed everything"
- Any phrasing that would read the same on a company's own marketing page
- "Check out [product]" as a standalone sentence

## Expressions to Use

- Specific place names, distances, prices, seasons
- "We stayed...", "Booked through...", "Ended up at..."
- Plain, slightly formal register

---

## Review Process

```
1. Identify thread type
2. Confirm you have genuine, specific local knowledge — if not, don't answer
3. Check personalization checklist above
4. Confirm: does this read like a local giving advice, or like marketing copy?
5. If a product mention is present, confirm the user explicitly accepted
   the elevated TripAdvisor-specific risk (see SKILL.md warning) — if not, remove it

PASS → Post / FAIL → Revise and re-review
```
